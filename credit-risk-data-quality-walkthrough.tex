\subsubsection{Overview}\label{overview}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subparagraph{\texorpdfstring{\textbf{Phase 1. Generating features
(predictors) for the business
world}}{Phase 1. Generating features (predictors) for the business world}}\label{phase-1.-generating-features-predictors-for-the-business-world}

Have to define both the variables and their distributions /
dependencies.

1: \textbf{Root variables}

\begin{enumerate}
\def\labelenumi{\alph{enumi})}
\tightlist
\item
  \textbf{firm age}: right skewed so using gamma distribution
\item
  \textbf{sector}: can be 1 of 3 sectors with different probabilities
\end{enumerate}

2: \textbf{Chained regression dependencies}

Each variable is determined by the one in front of it -- older firms
tend to be larger, larger firms tend to have lower leverage Plus --
adding randomness

\begin{enumerate}
\def\labelenumi{\alph{enumi})}
\setcounter{enumi}{2}
\tightlist
\item
  \textbf{log\_assets}: proxy for firm size, dependent on age and sector
\item
  \textbf{debt to equity}: higher leverage is more dangerous
  --\textgreater{} dependent on how big the firm is and how old it is
\item
  \textbf{interest\_cov}: proxy for cash flow
\item
  NEW -- ADDED -- \textbf{Crefo score}. Dependent on most things above.
  Sometimes gets lagged (not updated every year)
\end{enumerate}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subparagraph{\texorpdfstring{\textbf{2. Choose the true coefficients
that define the
world}}{2. Choose the true coefficients that define the world}}\label{choose-the-true-coefficients-that-define-the-world}

This is the ``ground truth'' -- can be confirmed from RR All are
standardized (change in log-odds per 1 SD increase)

beta0 \textless- -3.5 this is the intercept -- should be whatever the
default rate is beta\_log\_assets \textless- -0.2 larger firms less
likely to default beta\_debt\_to\_equity \textless- 0.4 higher leverage
= higher risk beta\_interest\_cov \textless- -0.3 higher coverage =
lower risk beta\_sector \textless- 0.2 manufacturing slightly riskier
beta\_firm\_age \textless- -0.1 older firms slightly safer beta\_crefo
\textless- 0.3 higher Crefo score → higher default risk

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subparagraph{\texorpdfstring{\textbf{3. Create panel data with time
series
component}}{3. Create panel data with time series component}}\label{create-panel-data-with-time-series-component}

Inner loop - creating firms that either stay the same over time, get
worse, or improve\ldots{} (drift rates); default or not during their 3-7
year loan periods. Crefo will sometimes refresh itself, sometimes
remaining stale

Outer loop creates lots of these firms. Then the rows are bound together

\begin{itemize}
\tightlist
\item
  the ``linpred'' part -- weighted sum of the predictors. this is
  logistic regression

  \begin{itemize}
  \tightlist
  \item
    computes the log-odds of default for each borrower
  \end{itemize}
\item
  pd\_true: then after: the logistic transformation so we get the true
  PDs and not log-odds
\end{itemize}

Draw observed defaults. For each borrower, draw a default with pd\_true
value from before - borrowers can have same PDs but 2 different outcomes
(default or not)

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subparagraph{\texorpdfstring{\textbf{4. Reporting and returning a list
}}{4. Reporting and returning a list }}\label{reporting-and-returning-a-list}

\begin{itemize}
\tightlist
\item
  Data has both raw and scaled versions of every variable
\item
  Scaling = the mean and SD of every predictor so you can apply
  consistently to the impaired datasets
\item
  Also saving the bounds for winsorization and plausibility (related to
  data preparation and FRS scores)
\end{itemize}

True betas = ground truth coefficients

\subsubsection{MISSINGNESS}\label{missingness}

\paragraph{\texorpdfstring{\textbf{Impairment 1:
MCAR}}{Impairment 1: MCAR}}\label{impairment-1-mcar}

MCAR: missingness applied independently to each cell at random.

Every cell has the same probability of being missing regardless of any
other value in the dataset --- no row-level or variable-level
dependence. This is implemented via independent rbinom draws per
variable, producing a random scatter of missingness across the data

Variables included: financial ratios and firm\_age. Sector and Crefo are
excluded: sector is a simple categorical entry unlikely to be missing;
Crefo missingness is modelled separately under the MAR condition.

Mild: \textasciitilde8\% missing per cell, Severe: \textasciitilde28\%
missing per cell

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

Explanation of what happens in this function:

\begin{itemize}
\tightlist
\item
  first: define function and its inputs (clean data, severity with
  default as ``mild'' if we don't specify
\item
  switch: mapping mild to 0.08 and severe to .28
\item
  make a copy of the clean dataset to work on
\item
  identify the financial variables that will get missingness / apply
  same impairment logic to each one
\item
  actual mcar mechanism: flip a weighted coin for each of the n firms
  --- it returns 1 (missing) with probability miss\_prob and 0
  (observed) with probability 1 - miss\_prob. The == 1 converts that
  into a logical vector of TRUE/FALSE, where TRUE means that firm's
  value will be set to missing. Every firm has exactly the same
  probability of being missing regardless of anything else about them
  --- that's what makes it MCAR.
\item
  where ``missing idx'' is true (1), replace with NAs
\item
  metadata: attaching tags to an object without making columns in a
  dataframe
\item
  return the impaired dataset
\end{itemize}

\paragraph{\texorpdfstring{\textbf{Impairment 2:
MAR}}{Impairment 2: MAR}}\label{impairment-2-mar}

MAR: missingness in crefo depends on firm\_age (fully observed)

Mechanism: younger firms are less likely to have a Creditreform score
because they lack sufficient credit history for the bureau to have
issued a rating.

This is MAR because the missingness predictor (firm\_age) is often
observed and is a different variable from the one with missing data
(crefo) --- consistent with Little \& Rubin (2002) and Zhang (2023,
p.~116). The logistic regression method is used for realistic gradual
probability change (Zhang, 2023, p.~116). Domain justification:
confirmed with company supervisors --- new market entrants frequently
lack Creditreform coverage in German B2B lending.

Explanation of what happens in this function: - (-3.5) / (-1.5) are the
log-odds of missingness (intercept) when firm\_age = 0 (tuned until the
average missing rate across simulated firms is \textasciitilde8\% or
28\%) - Plogis(): each firm gets its own missing probability based on
its age - Check for the average of all indiv. probabilities (8\% / 28\%)
- Applying missingness: rbinom flips a weighted coin for each firm using
their probability made above Result: when something gets set to 1, then
it becomes an ``NA'' - Rescale with clean parameters (mean and SD), tag
with metadata

\paragraph{\texorpdfstring{\textbf{Impairment 5: Implausible
Values}}{Impairment 5: Implausible Values}}\label{impairment-5-implausible-values}

Implausible values: inject a mix of domain-invalid, extreme outlier, and
subtly wrong values into financial predictors.

Unlike the missingness impairments, implausible values are designed to
be heterogeneous --- mixing obvious violations with harder-to-detect
distortions. This reflects real-world data quality issues: decimal
shifts, unit confusion, stale data, and system migration artefacts do
not produce uniform error patterns.

Three error types per variable: 1. Domain-invalid: clearly impossible
values (negative age, etc.) 2. Extreme outlier: technically possible but
far outside normal range 3. Subtle: within plausible range but wrong
(decimal shifts, swaps)

Severity controls the total \% of rows corrupted per variable.
PLACEHOLDER rates --- to be confirmed with company supervisors.
